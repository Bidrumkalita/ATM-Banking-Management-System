
# ATM Banking Management System

## Problem Statement

Many daily banking activities require customers to check balances, withdraw cash, deposit money, and review transactions. Performing these tasks manually can be time-consuming and inconvenient. This project provides a simple ATM Banking Management System that allows users to perform basic banking operations securely using PIN authentication.

---

## Scope of the Project

The project simulates the working of an Automated Teller Machine (ATM). It allows users to log in using a valid PIN and perform various banking operations through a menu-driven interface.

The scope includes:

- User Authentication
- Balance Inquiry
- Cash Deposit
- Cash Withdrawal
- Transaction History
- PIN Change Facility

---

## Target Users

- Bank Customers
- Students learning Python programming
- Educational institutions for demonstration purposes

---

## High-Level Features

### Authentication Module
- PIN Verification
- Login Validation
- Limited Login Attempts

### Banking Module
- Check Account Balance
- Deposit Money
- Withdraw Money

### Transaction Module
- Store Transaction Records
- View Transaction History

### Security Module
- Change PIN
- Input Validation
- Error Handling

---

## Expected Outcome

The system should allow users to securely access their account, perform banking operations, maintain transaction records, and demonstrate the practical application of Python programming concepts such as functions, loops, conditional statements, lists, and dictionaries.
