
# ATM Banking Management System

## Project Overview

The ATM Banking Management System is a Python-based application developed as part of the Problem Solving and Programming course. The project simulates the basic operations of an Automated Teller Machine (ATM) and allows users to perform banking transactions securely through PIN authentication.

The system provides functionalities such as balance inquiry, cash deposit, cash withdrawal, transaction history tracking, and PIN change operations.

---

## Problem Statement

Customers need a simple and secure system to perform banking transactions without visiting a bank branch. This project simulates ATM operations and provides an easy-to-use interface for basic banking activities.

---

## Objectives

- Implement secure ATM login using PIN verification.
- Allow customers to check account balance.
- Enable cash deposit and withdrawal operations.
- Maintain transaction history records.
- Apply Python programming concepts learned in the course.
